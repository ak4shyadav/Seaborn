# Assignment 10: Pandas (Series, DataFrame, Functions, Filtering & Analysis)

## Overview

This assignment focuses on using **Pandas** for handling, analyzing, and visualizing tabular data. It covers Series, DataFrames, mathematical operations, filtering, and basic data analysis.

## Topics Covered

- Pandas Series
- Mathematical operations on Series
- Python functions with Series
- Creating and working with DataFrames
- Important DataFrame functions
- Data filtering
- Basic data analysis
- Simple plotting using Pandas

## Tasks

The assignment includes tasks related to:

- Creating and working with Pandas Series
- Performing mathematical operations on Series
- Applying Python functions to Series
- Creating and manipulating DataFrames
- Using common DataFrame functions
- Filtering data based on conditions
- Performing basic analysis on sales and student data
- Creating simple graphs using Pandas

## Restrictions

- Use Pandas only. NumPy may be used indirectly.
- Avoid loops when Pandas operations can be used.
- Keep graphs simple and readable.
- Do not use advanced EDA, Machine Learning, or complex visualizations.

## How to Run

1. Make sure Python 3.x is installed.
2. Install Pandas:
pip install pandas
3.Open the assignment folder in VS Code or Jupyter Notebook.
4.Import Pandas: import pandas as pd
5.Run each task in the given order.
6.Check the results in the notebook or terminal.

Learning Objective

The main objective is to understand how Pandas Series and DataFrames are used to organize, manipulate, filter, and analyze tabular data. These skills provide a foundation for data analysis and upcoming Data Science concepts.
