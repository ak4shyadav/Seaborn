# Assignment 11: Matplotlib

## Topic

**Matplotlib – Core Plot Types & Visualization**

## About the Assignment

This assignment is about using Matplotlib to create different types of charts for data visualization.

The following types of plots are covered:

* Line Plot
* Scatter Plot
* Vertical Bar Plot
* Horizontal Bar Plot
* Multiple Bar Plot
* Stacked Bar Chart
* Histogram
* Pie Chart

The plots are created using Matplotlib directly, without using Seaborn or Pandas plotting functions.

## Requirements

* Python 3
* Matplotlib

Install Matplotlib using:

```bash
pip install matplotlib
```

## Tasks Covered

### Task 1: Line Plot

Shows the monthly sales trend using a line chart.

### Task 2: Scatter Plot

Shows the relationship between sales and profit using a scatter plot.

### Task 3: Bar Plot

Creates both vertical and horizontal bar charts to compare sales across categories.

### Task 4: Multiple Bar Plot

Compares sales of different years across different product categories.

### Task 5: Stacked Bar Chart

Shows the combination of online sales and store sales for different categories.

### Task 6: Histogram

Shows the distribution of student marks using a histogram.

### Task 7: Pie Chart

Shows the percentage market share of different products.

## Libraries Used

Only Matplotlib is used for creating the visualizations.

```python
import matplotlib.pyplot as plt
```

No Seaborn or Pandas plotting functions are used.

## How to Run

Open the project folder in a Python editor or terminal and run:

